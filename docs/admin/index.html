Your cloud working copy

Apply any open form, then use Save private draft above to keep your edits online. Drafts are not public. Reload fetches the newest cloud version and replaces this working copy, so export a backup first if you need it.

Publish your portfolio

Preview the working copy before publishing. Publishing first saves the private draft, then updates the live portfolio. It does not create a GitHub commit.
